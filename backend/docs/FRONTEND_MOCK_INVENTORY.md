# Frontend Mock Data Inventory

> **Status:** VERIFIED AGAINST UI — shapes extracted directly from the
> frontend source code in `src/`.

This document catalogs every mock / hard-coded data shape consumed by
the CyRIS frontend.  It was generated by scanning every `.ts` / `.tsx`
file under `src/data/mock/`, `src/types/`, `src/utils/`, `src/services/`,
`src/state/`, and `src/pages/`.

## 4. Frontend Utilities (`src/utils/`)

### `riskEngine.ts`
- `BASELINE_EAL = 4_20_00_000` (₹4.2 Cr)
- `BASELINE_VAR95 = 18_00_00_000` (₹18 Cr)
- `calculateROSI(riskReduction, cost) → number`
- `calculateVaR(eal, baselineEal, baselineVar) → number` (linear scaling)
- `calculateRiskReduction(selectedIds, controls, baselineEal) → number` (submodular)
- `calculateEAL(selectedIds, controls, baselineEal) → number`
- `simulateControlChange(selectedIds, nextId, controls, baselineEal) → { before, after, reduction, cost, rosi }`
- `optimizeBudget(budget, controls, baselineEal, alreadySelected) → OptimizationResult`
- `postureFromEal(eal, baseline) → Severity`
- `investmentCurve(controls, baselineEal, steps) → { spend, eal, reduction }[]`

### `formatINR.ts`
- `formatINR(value) → string` (Indian grouping: ₹4,20,00,000)
- `formatINRDelta(value) → string`
- `formatROSI(ratio) → string`
- `formatPercent(value) → string`
- `formatTimestamp(iso) → string`

### `terminology.ts`
- `terminology: Record<string, TermDefinition>` — glossary used by `TechnicalTooltip`
